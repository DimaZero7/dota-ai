# 5. Реализовать числовые признаки и обобщения уровней L1–L4

Статус: Выполнена

## Описание

Превратить сохранённые события в разнообразное компактное описание игры по каталогу задачи [4](4.md). Основную обработку нижних уровней выполняет код: вычисляет признаки эпизодов, новые показатели этапов и траекторию матча. Текущий Codex подключается выборочно для вопросов, требующих интерпретации, а не пишет обязательный текст на каждое окно каждого матча.

## Ожидаемый результат

Вызываемые сервисы и версионируемые результаты L1–L4, пригодные для межматчевой статистики и обновления без повторного чтения событий аналитиком. На существующих десяти играх представлены реальные значения, различия и покрытие; как минимум золото, опыт/уровни, фарм, смерти и участие имеют самостоятельные признаки, а не сводятся к KDA и net worth.

## Зависимости и границы

После [4](4.md); результат используется в [6](6.md)–[10](10.md). Существующие источники и десять реальных матчей, без меты, новых загрузок и внешнего API модели. Реализуется обязательное ядро и доступные дополнительные показатели утверждённого каталога. Недоступные величины возвращают явный статус с причиной.

## Подзадачи

- [x] Реализовать общий результат измерения с версией, единицами, покрытием, исходными ссылками и контекстом. Развести наблюдение источника, производный расчёт, приближение и модельную оценку; обеспечить совместимость с новой схемой уровней и сохранение старых артефактов.
- [x] Вычислять экономику, опыт и уровни по интервалам: темп, изменения относительно подходящих участников/команды, распределение доступных источников дохода и опыта, моменты достижения уровней и перерывы в развитии. Проверять согласованность журналов и итогов отдельно для каждого показателя.
- [x] Вычислять признаки фарма и присутствия: добивания, доступные типы ресурсов, активное время, длительности перерывов и возвращение к развитию после событий. Отсутствие событий не объявлять бездействием при неполном покрытии.
- [x] Вычислять признаки смертей и повторного включения: время и этап, длительность отсутствия, интервалы между потерями, доступное состояние перед следующим действием, изменение ресурсов и командного положения. Не подменять наблюдаемые последствия утверждением о предотвратимости или потерянном потенциальном золоте.
- [x] Реализовать доступные признаки участия, урона, лечения, покупок, применений предметов и способностей. Проверить правила выделения столкновений, неполные журналы и принадлежность участников; отсутствие применения не считать доказанной упущенной возможностью.
- [x] Из признаков эпизодов формировать новые показатели этапов: частоты с знаменателями, распределения длительностей, темп и его изменения, сочетание получения ресурсов и участия. Учитывать пересечения без двойного счёта; разделять окна сравнения и наблюдаемые изменения состояния игры.
- [x] Формировать компактный числовой результат матча L4: траектория ресурсов/опыта, переходы состояния, распределение времени и вклада, признаки эпизодов и этапов, контекст героя/роли/пиков и покрытие. Сохранять достаточно данных для будущих сравнений без передачи всех событий вверх.
- [x] Подключить выборочную интерпретацию сложного эпизода с ограниченным входом и структурированным выходом. Сохранять основания и неопределённость, переиспользовать оценку при неизменных входах; типовой числовой путь L1–L4 должен работать без модельных ответов.
- [x] Вывести таблицы новых показателей на десяти матчах и проверить расчёты по исходным полям и выбранным событиям. Показать не только значения, но и примеры того, какие дополнительные различия стали видны; неподтверждённые методы уточнить либо исключить.
- [x] Добавить необходимые проверки формул, времени, пропусков, пересечений и несовместимых данных; документировать сервисы, команды, результаты и ограничения в RU/EN.

## Критерий завершения

Обычный матч проходит L1–L4 без обязательного авторского разбора. Выход содержит разнообразные проверенные числовые признаки и происхождение; новые показатели этапа и матча вычисляются из нижних данных. Неполнота одного показателя не исключает остальные данные матча.

## Результат

- Реализован пакет [numeric](../../../src/apps/analysis/numeric/services.py): отдельные версии L1–L4, вызываемые сервисы, CLI, кеш по исходникам/каталогу/параметрам/коду и проверка всей цепочки зависимостей. Авторские артефакты задачи 3 сохранены.
- Работают минутные окна и десятиминутные этапы; экономика и XP по причинам, уровни и разрывы записей, фарм, объединение интервалов смерти, возврат со снимками состояния, участие по финальным данным, разделение урона оригинальным целям/иллюзиям, лечение, покупки/применения, записанные варды и объекты. L4 сохраняет траекторию и знаменатели для будущих сравнений.
- Добавлен отдельный ограниченный обмен для интерпретации выбранной смерти текущим Codex. [Пример](../../../data/prototype/numeric-review-example.json) принят и повторно прочитан с проверкой исходников/зависимостей; числовой путь не требует таких ответов.
- Подготовлены [RU](../../../docs/ru/development/numeric-analysis.md) / [EN](../../../docs/en/development/numeric-analysis.md), команды и таблицы новых показателей на десяти матчах. [Результат проверки](../../../data/prototype/numeric-verification.json) хранит значения, качество и ссылки на локальные артефакты.
- L4 занимает 43 904–53 104 UTF-8 байта на матч; L1 больше примерно в 70–160 раз. Это размер полного числового артефакта, не пакета модели. Список всех матчей не предназначен для загрузки в контекст аналитика.

## Проверка и уточнение методов

Прошли 36 тестов (16 новых, 20 прежних). На реальных снимках проверены 186 ссылок на выбранные записи, прямые суммы золота/XP, независимое объединение секунд смерти, участие по OpenDota, границы и сложение окон/этапов. Повторный расчёт дал те же ревизии; кеш переиспользуется. Новых матчей, сетевых запросов и обязательных ответов модели — 0.

При проверке обнаружено, что простой суммарный урон включает цели-иллюзии. Добавлено раздельное представление принадлежности урона; оставшиеся расхождения с финалом явно сохранены. Кластеры урона не названы полными командными драками, разрывы записей — бездействием, время смерти — ценой предотвратимой ошибки. Качество каждого журнала независимо, поэтому неполные ассисты не исключают остальные признаки матча.

Пространственные признаки относятся к задаче [6](6.md); сессионная последовательность — к [7](7.md). Их статусы и причины в L4 явные. Эффективный обзор, полная доступность предметов/способностей, семантика стэков из минутного массива и атрибуция преобразования убийств в объекты не выдумываются. Накопительное хранение, L5–L6 и проверка устойчивости остаются задачами 7–10.
