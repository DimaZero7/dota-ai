# 9. Перенести основную работу аналитика на L5–L6 и обновлять профиль по изменениям

Статус: Выполнена

## Описание

Оптимизировать текущий Codex как аналитика: в обычном сценарии получать накопленные числовые сведения, условия сравнений, изменения после новых матчей и состояние гипотез. Подробности нижних уровней раскрывать для конкретного противоречия, необычного случая или проверки объяснения.

Профиль должен описывать группы ситуаций и их изменения так, чтобы читателю не требовалось помнить отдельные матчи. При этом окончательное связывание наблюдений, выбор полезных гипотез и объяснение направлений развития выполняет аналитик, а не жёсткие правила присвоения черт по одному числу.

## Ожидаемый результат

Рабочий путь «обновлённая статистика → ограниченный пакет L5 → пересмотр гипотез → личный L6 и объяснение изменений». Основной пакет не растёт за счёт добавления текста каждого матча. Сохраняется возможность проверить конкретное основание и разобрать отдельный матч с учётом подходящего профиля.

## Зависимости и границы

После [4](4.md), [7](7.md), [8](8.md); используются результаты [5](5.md) и [6](6.md). Текущий Codex через локальный обмен данными, без отдельного API модели. Новые реальные игры не собираются. Статистическая модель поведения и обновление профиля не объявляются обучением весов нейросети. Персональные выводы на имеющихся десяти играх остаются предварительными.

## Подзадачи

- [x] Собирать ограниченный пакет для аналитика: релевантные накопленные показатели и распределения, условия групп, знаменатели, покрытие, изменения недавнего периода, текущие гипотезы и противоречия. Не включать автоматически все карточки матчей или все нижние тексты.
- [x] Добавить определения и правила чтения числовых признаков: единицы, направление изменения, сравниваемые условия и смысл ограничений. Аналитик должен понимать число без чтения истории, но не превращать его в заранее назначенный психологический ярлык.
- [x] Разделить первичное формирование профиля и последующее обновление. При добавлении матчей передавать прежнее компактное состояние и изменения; отсутствие существенного изменения смысла допускает сохранение прежней формулировки с обновлёнными основаниями.
- [x] Хранить жизненный цикл гипотез: обнаружена, проверяется, поддержана, ослабла, отвергнута. Сохранять критерии проверки, версии, область применимости, поддержку и противоречия; не повышать уверенность просто из-за повторения текста в верхних уровнях.
- [x] Реализовать адресное раскрытие группы, компактной карточки матча, этапа и эпизода с ограничением числа обращений и размера результатов. Давать репрезентативные случаи и контрпримеры, отмечать способ выбора и оставшиеся непроверенные вопросы.
- [x] Вызывать интерпретацию на нижнем уровне только при содержательной необходимости; сохранять структурированную оценку с основаниями и неопределённостью. Не требовать нового модельного разбора неизменившегося эпизода и не выдавать автоматический расчёт за ответ Codex.
- [x] Формировать L6 через характеристики и условия: наблюдаемая особенность, числовые основания по группе, альтернативное объяснение, актуальность, изменение и проверяемое направление развития. Убирать фразы, зависящие от памяти о матче «против Arc»; примеры должны раскрываться отдельно с понятным контекстом и ID.
- [x] Поддержать разбор выбранного матча через профиль подходящего периода и контекста. Исключать сам матч из оснований независимого сравнения; для оценки прогноза использовать только прошлые данные. Отмечать ретроспективность и уже увиденный аналитиком материал, если пример не является слепой проверкой.
- [x] Измерить размер основного входа, объём раскрытий, число обращений и количество прочитанных карточек. Задать бюджеты и приоритеты под вопрос; учитывать, что контроль размера файла не означает автоматической изоляции памяти текущей сессии или точного контроля её токенов.
- [x] Провести реальную аналитическую сессию по сводным данным и обновлению на имеющейся выборке. Показать профиль до/после и журнал причин изменения, проверить несколько оснований по нижним данным, исправить потерянные ограничения и чрезмерные обобщения. Представить отчёты и команды в RU/EN.

## Критерий завершения

Типовой профиль и его обновление строятся без необходимости держать каждую игру в контексте. Выводы ссылаются на понятные числовые основания и условия; конкретные матчи раскрываются по необходимости. Аналитик может сохранить, уточнить или отвергнуть прежнее объяснение, а не обязан усиливать его после каждого пополнения.

## Результат

Выполнено 05.09.2026. Реализован пакет `src/apps/analysis/analyst/`: ограниченный L5, определения показателей, значения до/после, сохранение/редакция авторского L6, жизненный цикл гипотез, история версий, адресные раскрытия и кэш необязательных нижних оценок. Сервисы доступны через CLI; дополнительных зависимостей и API модели нет. Содержательные ответы написал текущий Codex.

Основной вход — до 32 000 UTF-8 байт; раскрытия — до четырёх обращений, суммарно 12 000 байт. Поддержаны отдельные группы, карточки, этапы и эпизоды; квоты сохраняются. Сам матч исключается из независимой базы и популяции выбранного профиля; прошлое ограничивается играми, завершёнными до цели. Отсутствующий подходящий профиль показывается явно. Проверочный режим forecast скрывает итоговые признаки цели и запрещает раскрытия, но не объявляется слепым прогнозом на ранее виденном материале.

Реальная сессия использовала семь ранних игр и три оставшиеся из прежней десятки. Основные входы: 31 074 и 31 444 байта, по ноль карточек. Первоначально раскрыты три случая группы и адресно L2/L3 одного из них: пять передач карточек, три уникальных матча, 11 223 байта. При обновлении — одно раскрытие, 3190 байт, одна повторно использованная оценка, ноль новых нижних ответов. Портрет Jakiro-mid сохранён: новых наблюдений его роли не добавилось; дополнительный Jakiro относится к пятой позиции и не смешан с мидом.

Дополнительно показан Jakiro 8959040566 через профиль на более раннем срезе: три предшествующих сопоставимых игры, цель исключена. Для Death Prophet 8960626424 подходящих предшествующих игр/профиля нет; перенос выводов Jakiro отклонён. Новых реальных матчей не получено, уникальная популяция остаётся десять игр, мета отключена.

Прошли 120 тестов, включая 20 новых, проверка локальных сеансов, CLI и RU/EN-ссылок. Проверен предел основного входа на 1000 искусственных играх. Ограничения: нет изоляции памяти текущего диалога и измерения точных токенов; ранний профиль написан сейчас в ретроспективном воспроизведении. Смысловая истинность, причинность, эффект рекомендаций и устойчивость полного профиля этим не доказаны. Веса нейросети не обучаются.
