# 7. Реализовать статистику дистанции, игровые сессии и поиск условных связей

Статус: Выполнена

## Описание

Из компактных результатов матчей формировать новые макропоказатели: распределения, стабильность, изменения во времени, условные связи с исходом и особенности последовательностей игр. Дать аналитику возможность исследовать сочетания опыта, ресурсов, риска, участия, пространства и истории игры без чтения каждого матча.

## Ожидаемый результат

Структурированный результат L5 с группами сравнения, числом наблюдений, величиной различий, покрытием, ограничениями и ссылками на раскрываемые примеры. Отдельно представлены наблюдения по матчам, сессиям и сериям; гипотезы для проверки отделены от подтверждённых измерений и причинных объяснений.

## Зависимости и границы

После [4](4.md)–[6](6.md). Прежние десять игр сохраняются как отдельный пример. По дополнительному разрешению пользователя от 05.09.2026 выборка расширяется до всех доступных рейтинговых матчей августа 2026, границы месяца — по Москве. Пропуски источников показываются отдельно. Малая выборка не должна создавать видимость надёжной статистики; большие сценарии проверяются также на явно искусственных данных. Без меты; известные патчи и версии карты ограничивают сопоставимость. Психологические ярлыки по результатам матчей не формируются.

## Подзадачи

- [x] Реализовать распределения и устойчивость показателей по группам: количество, подходящие средние/медианы/квантили, разброс и крайние случаи. Развести среднее по матчам и величину на суммарное время/число возможностей; не усреднять проценты без учёта знаменателей.
- [x] Формировать объяснимые группы сравнения по герою, позиции, этапу, режиму, стороне и известным условиям. Сохранять контекст обоих пиков, состояние команды и доступный уровень участников; показывать малые группы, пропуски и ограничения объединения.
- [x] Вычислять условные связи с победами и поражениями, включая распределение смертей по этапам и состоянию до события, ресурсы/опыт, участие и объекты. Учитывать длительность и зависимость эпизодов внутри игры; не считать каждый эпизод отдельным независимым исходом матча.
- [x] Поддержать вопросы по совместным изменениям: золото × опыт, участие × восстановление ресурсов, повторные потери × состояние команды, покупка × последующее поведение, маршрут × потери. Хранить определения условий и подходящие контрольные случаи; совместное изменение не выдавать за причину.
- [x] Определить предполагаемые игровые сессии по доступной хронологии и перерывам. Версионировать правило, проверить чувствительность к границе перерыва и учитывать неполную историю; не утверждать фактическую непрерывность игры без оснований.
- [x] Вычислять последовательности результатов, длины серий, порядок игры в сессии, переходы после победы/поражения и смену героя/роли. Отделить изменение поведения от изменения одного винрейта; не приписывать результат усталости или тильту.
- [x] Сопоставлять общую историю и недавние периоды внутри совместимых групп. Показывать изменение состава выборки и покрытия, чтобы смена роли, героя или доступности данных не выглядела изменением навыка.
- [x] Организовать поиск кандидатов связей с приоритетом по размеру различия, покрытию, повторяемости и практической проверяемости. Для массового поиска предусмотреть множественные сравнения, зависимые наблюдения и отделение исследовательской выборки от последующей проверки.
- [x] Подготовить компактные числовые сводки и выборочное раскрытие поддерживающих/противоречащих случаев. Основное описание должно говорить об условии и группе наблюдений, а не требовать помнить конкретный матч «против Arc».
- [x] Вывести новые макропоказатели на имеющихся данных, показать недостаточность материала там, где она есть, и проверить методы на искусственных сценариях с известными связями и ложными совпадениями. Документировать результаты и ограничения в RU/EN.

## Критерий завершения

L5 создаёт новые данные из результатов матчей, а не просто собирает их тексты. Доступны условные связи, временная динамика и статистика последовательностей с честными знаменателями. Отсутствие статистически убедительной связи считается допустимым результатом; оно не компенсируется выдуманным профилем.

## Результат

05.09.2026 реализован пакет `src/apps/analysis/longitudinal/`: отдельные числовые подписи L4, распределения и группы L5, совместные признаки, хронология, сравнение периодов, исследовательские кандидаты и адресное раскрытие. Пакет аналитика ограничен 32000 байт, раскрытие — 8000 байт за три вызова. 80 тестов проходят, включая искусственные 1000 строк и известную/ложную связь. Проверен воспроизводимый пересчёт из подписей без чтения исходных журналов.

Исходные десять игр сохранены отдельно. В августе выбраны 45 рейтинговых матчей, OpenDota получен для всех. Полный STRATZ доступен для 23; 22 пропуска после HTTP 503 сохранены явно. Хронология использует все 45, подробный L5 — 23, с 394 группами и 110 объявленными парами. Статистически воспроизведённых связей нет; пакет занимает 31157 байт. Неполнота STRATZ ограничивает реальные выводы и не скрывается как успешный полный сбор.
