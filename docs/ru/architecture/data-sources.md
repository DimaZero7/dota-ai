[Архитектура](README.md) · [English](../../en/architecture/data-sources.md)

Статус: сравнение выполнено, рекомендация ожидает решения пользователя. Реплей и собственный парсер исключены из текущей задачи по запросу пользователя.

## Основание

Один матч `8960626424`, игрок `203182675`, Death Prophet. Использованы сохранённые 05.09.2026 ответы, без повторных запросов или смены матча:

- [OpenDota: отчёт и исходные данные](../../../data/matches/8960626424/opendota/20260905T090414.607209Z/report.ru.md).
- [STRATZ: отчёт, запросы и исходные данные](../../../data/matches/8960626424/stratz/20260905T091417.870926Z/report.ru.md).

Оба источника покрывают 10 игроков. По account_id сопоставлены участники, проверены герои. Все **110 сравнений** совпали: по 11 показателей каждого игрока — kills, deaths, assists, last hits, denies, GPM, XPM, net worth, hero damage, tower damage и healing. Совпадение итогов не подтверждает полноту событий или независимость источников.

## Покрытие

Числа в строках игрока относятся к целевому игроку, остальные — ко всему матчу. Число записей не равно качеству или числу уникальных игровых действий.

| Категория | OpenDota | STRATZ | Практическое значение |
| --- | --- | --- | --- |

| Временные ряды игрока | По 53 точки times/gold_t/xp_t/lh_t/dn_t; times 0–3120 с | Обычно 52 точки поминутной статистики, 53 networthPerMinute | Нужна проверка единиц, времени и накопительных/интервальных значений |
| Позиции и здоровье | Агрегаты lane_pos, без аналогичного журнала перемещений в полученном ответе | 1860 обновлений позиции, 2349 здоровья | STRATZ подходит для восстановления последовательности ситуаций; это не каждый игровой кадр |

STRATZ-запросы охватили доступные поля выбранных веток матча, stats и playback. Переходы к истории аккаунтов, справочникам и средним показателям других матчей не запрашивались; исключения перечислены в метаданных. Утверждения об уникальности относятся к этим двум выгрузкам, а не ко всем возможностям API.

## Практические затраты

| Критерий | OpenDota | STRATZ |
| --- | --- | --- |
| Авторизация при сборе | Без ключа | Бесплатный токен после входа через Steam; хранится локально |
| Наблюдаемая квота | После запроса матча оставалось 59/мин и 2985/день; это остаток, не размер тарифа | Заголовки limit: 8/сек, 150/мин, 1500/час, 15000/день |
| Запросы текущего сборщика | 2: матч и схема | 13: схема, обзор, stats, playback 10 игроков |
| Байты исходных ответов со схемой | 397091 (~0,40 МБ) | 11466707 (~11,47 МБ) |
| Весь локальный снимок на момент сравнения | ~0,96 МБ | ~37,29 МБ, включая объединённую копию и инвентаризацию |
| Ожидание разбора | Матч уже разобран; ожидание очереди не измерялось | Матч уже разобран; ожидание очереди не измерялось |
| Получение | Между первым и последним ответом ~0,5 с | ~33,3 с, включая паузы сборщика 1,1 с между запросами |
| Поддержка | Простой REST-ответ; необязательные поля и версии парсера | Токен, схема GraphQL, несколько запросов, частичные ошибки и объединение |

Время между ответами не является полным временем запуска или сравнительным тестом скорости сервисов. Квоты зафиксированы по сохранённым заголовкам, могут меняться и расходятся с таблицей сайта STRATZ. Повторные запуски расходуют квоту; большие JSON игнорируются Git. Устойчивость доступа, время появления новых матчей и полнота истории по одному матчу не установлены.

## Рекомендация для согласования

Использовать **STRATZ как основной источник подробных событий, OpenDota как дополнение и проверку итогов**. Уже реализованный выбор матча через OpenDota оставить: порядок получения данных не определяет основной источник анализа.

Для следующего анализа брать последовательности перемещений, здоровья, способностей и урона из STRATZ; группировки драк, цели и дополнительные журналы — из OpenDota. Каждое наблюдение должно сохранять источник и время. При расхождении не перезаписывать один ответ другим и не смешивать события без проверки их определения. Недоступность STRATZ означает ограниченный анализ по OpenDota, а не равнозначную замену.

Вариант «только STRATZ» проще по числу интеграций, но теряет уже доступные дополнения OpenDota. Вариант «только OpenDota» проще по авторизации и объёму, но теряет подробную последовательность событий. Для цели индивидуального разбора сочетание двух источников выглядит обоснованным по текущему матчу.

Это рекомендация, а не уже согласованное решение или реализованный объединённый анализ. Окончательный выбор источников остаётся за пользователем.
