# Dota 2 reference underlay / Подложка карты

`dota-740.jpg` is the unchanged map asset distributed in the OpenDota web repository. Dota 2 artwork belongs to Valve; OpenDota's repository license is preserved in `OPENDOTA-LICENSE.txt`. The original URL, immutable repository revision and SHA-256 are recorded in `dota-740.json`.

The asset is labeled **7.40**, while the current ten-match sample uses **7.41**. It is a visual reference, not exact terrain or a walkability mask for those matches. Do not relabel it as 7.41. The renderer checks the asset hash and embeds the image in generated SVGs; no network request is made during rendering.

Изображение сохранено без изменений из OpenDota. Версия подложки — **7.40**, версия текущих матчей — **7.41**. Используется как визуальный ориентир с явной подписью версии, а не точная маска рельефа или проходимости. Исходный URL, ревизия и хэш — в `dota-740.json`; лицензия репозитория OpenDota приложена. При отрисовке хэш проверяется, изображение встраивается в SVG без сетевых запросов.
